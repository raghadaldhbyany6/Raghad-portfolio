# رغد — الموقع الشخصي

موقع عربي باتجاه RTL، بالأبيض والأسود مع لمسات بنفسجية. يعمل كموقع ثابت دون خدمات خلفية أو مفاتيح سرية أو اعتماديات تشغيل خارجية.

## تشغيل الموقع

يتطلب Node.js 20 أو أحدث (اختُبر على Node 24).

```sh
npm ci
npm run dev
```

الخادم يستخدم المنفذ `5173`. لتغييره: `PORT=3000 npm run dev`.

```sh
npm test
npm run build
SERVE_DIST=1 npm start
```

البناء ينسخ ملفات النشر فقط إلى `dist/`. استخدمي خادمًا محليًا بدل فتح HTML مباشرة، لأن الموقع يستخدم JavaScript modules.

## إضافة أعمالك الحقيقية

كل بيانات المعرض والأدوات والتواصل في **`data.js`**. لا يتطلب تحديث الأعمال تعديل HTML أو CSS.

### الصور

1. ضعي الصور في `assets/images/`، مثل `my-project-01.webp` و`my-project-02.webp`.
2. عدّلي عنصرًا موجودًا أو أضيفي عنصرًا في `portfolio.images`:

```js
{
  id: 'my-project', // فريد لكل مشروع
  title: 'اسم المشروع',
  category: 'تصميم بصري',
  description: 'وصف حقيقي للمشروع ودورك فيه.',
  images: ['assets/images/my-project-01.webp', 'assets/images/my-project-02.webp'],
  placeholder: false
}
```

الصورة الأولى غلاف البطاقة، والبقية تُعرض في النافذة المكبرة مع أزرار التنقل. يُدعَم Escape للإغلاق والأسهم للتنقل. على سطح المكتب تُرتب البطاقات في عمودي Masonry حسب ارتفاع الصور، وعلى الجوال في عمود واحد.

### الفيديو

1. ضعي ملف MP4 بترميز H.264/AAC في `assets/videos/`، وصورة الغلاف في `assets/images/`.
2. عدّلي أو أضيفي عنصرًا في `portfolio.videos`:

```js
{
  id: 'my-video',
  title: 'اسم الفيديو',
  category: 'فيديو إعلاني',
  description: 'وصف المشروع.',
  poster: 'assets/images/my-video-cover.webp',
  src: 'assets/videos/my-video.mp4',
  placeholder: false
}
```

يمكن استبدال `src` برابط HTTPS مباشر لملف MP4 أو رابط YouTube عادي أو مختصر أو Shorts أو رابط Vimeo. تُفتح الفيديوهات داخل الموقع ولا تبدأ تلقائيًا. بعض أصحاب الفيديوهات يمنعون التضمين؛ يجب السماح بالتضمين من إعدادات المنصة، وقد تحجب الشبكات المقيدة مشغلات الأطراف الخارجية. الروابط لصفحات خدمات أخرى مثل Google Drive لا تُعد روابط MP4 مباشرة.

اتركي `src: ''` و`placeholder: true` لإبقاء المكان التجريبي دون رفع أي فيديو. ضغطة التشغيل تعرض رسالة تجريبية صريحة. غيّري الملاحظة العامة في `index.html` بعد تحويل المعرض كله لأعمال حقيقية.

### التواصل والهوية

أضيفي بريدك في `portfolio.email` لتفعيل زر البريد. البريد فارغ افتراضيًا؛ لا توجد بيانات اتصال مختلقة أو نموذج يرسل بيانات. لتعديل التعريف والنصوص الثابتة استخدمي `index.html`، وللألوان والمسافات `styles.css`. لم تُضف روابط اجتماعية غير معروفة.

### شعارات الأدوات

الشعارات محفوظة محليًا في `assets/logos/`؛ لا يحتاج الزائر إلى تحميلها من مواقع خارجية. راجعي `assets/logos/SOURCES.md` للمصادر والعلامات التجارية. روابط البطاقات تقود إلى مواقع الأدوات.

## النشر على GitHub Pages — رابط عام مجاني

المشروع يتضمن إجراء نشر في `.github/workflows/deploy.yml`.

1. افتحي مستودع `raghadaldhbyany6/Raghad-portfolio` في GitHub.
2. من **Settings → Pages → Build and deployment → Source** اختاري **GitHub Actions**.
3. من تبويب **Actions** اختاري **Deploy portfolio to GitHub Pages** ثم **Run workflow** للفرع `main`، أو ادفعي تحديثًا جديدًا إلى `main`.
4. بعد نجاح الخطوات يظهر الرابط العام في **Settings → Pages** وفي نتيجة مهمة النشر. الرابط المتوقع، ما لم تغيّري الاسم أو النطاق:
   `https://raghadaldhbyany6.github.io/Raghad-portfolio/`
5. أي تحديث لاحق على `main` يعيد الاختبار والبناء والنشر تلقائيًا.

وجود الملف لا يعني أن Pages مفعّل أو أن الموقع منشور؛ يلزم اختيار GitHub Actions من الإعدادات ونجاح التشغيل. إذا كان المستودع خاصًا، تحققي من دعم GitHub Pages في خطتك أو اجعليه عامًا إن رغبتِ.

بديل: انشري مجلد `dist/` على Netlify، أو اربطي المستودع واستخدمي أمر البناء `npm run build` ومجلد الإخراج `dist`. لا تحتاجين متغيرات بيئة أو أسرارًا.

للفيديوهات الكبيرة استخدمي YouTube أو Vimeo بدل Git؛ GitHub يمنع الملفات الأكبر من 100 MiB، كما أن الفيديوهات الكبيرة تزيد زمن التحميل. حسّني الصور إلى WebP وحافظي على الأسماء والمسارات بالحروف نفسها.

## الفحوصات

`npm test` يختبر بيانات المشاريع ووجود الصور والشعارات وتحويل روابط الفيديو ورفض الروابط غير المدعومة. يُنفذ الاختبار والبناء في إجراء النشر أيضًا. اختبارات المتصفح الاختيارية: `npx playwright install chromium` ثم `npm run test:e2e`. لاستخدام Chromium مثبّت مسبقًا: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`. يختبر المتصفح نسخة البناء على سطح المكتب والجوال، وصحة تحميل جميع الصور والشعارات والتبويبات وتركيز لوحة المفاتيح والتضمين. يختبر التضمين دون الاتصال بـYouTube. اختبار تشغيل MP4 يحتاج `TEST_MP4_PATH` يشير لملف اختبار محلي؛ دون هذا المتغير يُسجّل متجاوزًا. لا يتضمن الموقع ملفات فيديو. لا يثبت اختبار الروابط وحده تشغيل فيديو خارجي؛ يعتمد ذلك على توفره وسماح صاحبه بالتضمين.
